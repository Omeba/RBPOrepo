# Требования безопасности

| ID   | Требование                                                                                                                                                                                                                                                                       | Критерий приёмки                                                                                                                                                                                                                                                                        | Связанные T / D (позднее) |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------- |
| SR-1 | Неавторизованный пользователь не должен иметь возможности создавать или удалять обсуждения и сообщения, а также создавать или удалять теги. Проверка должна выполняться сервером независимо от доступности соответствующих элементов интерфейса.<br><br>OWASP ASVS: v5.0.0-8.2.1 | Если неавторизованный пользователь отправляет запрос создания или удаления обсуждения, сообщения или тега, сервер отклоняет операцию. Состояние данных после запроса не изменяется.                                                                                                     | —                         |
| SR-2 | Участник может удалять только созданные им самим сообщения и обсуждения.<br>  <br>OWASP ASVS: v5.0.0-8.2.1                                                                                                                                                                       | При попытке участника удалить чужое сообщение / обсуждение сервер отклоняет операцию, состояние данных после запроса не изменяется. Удаление собственного сообщения / обсуждения завершается успешно.                                                                                   | T-1                       |
| SR-3 | Модератор может удалять только сообщения / обсуждения участников, а также созданные им самим сообщения / обсуждения / теги.<br><br>OWASP ASVS: v5.0.0-8.2.1                                                                                                                      | Запрос на удаление сообщения / обсуждения / тега другого модератора отклоняется сервером, состояние данных после запроса не изменяется; запрос на удаление сообщений / обсуждений участников, а также собственных сообщений / обсуждений / тегов завершается успешно.                   | —                         |
| SR-4 | Пользователь может создавать и удалять сообщения, обсуждения и теги только от своего лица.<br><br>OWASP ASVS: v5.0.0-8.3.1                                                                                                                                                       | При попытке создания или удаления сообщения / обсуждения / тега не от своего лица операция отклоняется сервером, данные на сервере не меняются; при попытке создания или удаления сообщения / обсуждения / тега от своего лица и наличии прав на действие операция завершается успешно. | —                         |
| SR-5 | Участник и модератор могут изменять пароль от своего аккаунта.                                                                                                                                                                                                                   | Попытка авторизации по новому паролю проходит успешно. Попытка авторизации по старому паролю завершается ошибкой.                                                                                                                                                                       | T-2                       |
| SR-6 | Данные авторизации хранятся только на сервере.                                                                                                                                                                                                                                   | После авторизации данные о логине и пароле пользователя не сохраняются в веб-клиенте.                                                                                                                                                                                                   | T-2                       |
