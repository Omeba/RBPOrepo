# Требования безопасности

| ID   | Требование                                                                                                                                                                                                                                                                       | Критерий приёмки                                                                                                                                                                                                                          | Связанные T / D (позднее) |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------- |
| SR-1 | Неавторизованный пользователь не должен иметь возможности создавать или удалять обсуждения и сообщения, а также создавать или удалять теги. Проверка должна выполняться сервером независимо от доступности соответствующих элементов интерфейса.<br><br>OWASP ASVS: v5.0.0-8.2.1 | Если неавторизованный пользователь отправляет запрос создания или удаления обсуждения, сообщения или тега, сервер отклоняет операцию. Состояние данных после запроса не изменяется.                                                       | —                         |
| SR-2 | Участник может удалять только созданные им самим сообщения и обсуждения.<br>  <br>OWASP ASVS: v5.0.0-8.2.1                                                                                                                                                                       | При попытке участника удалить чужое сообщение / обсуждение сервер отклоняет операцию, состояние данных после запроса не изменяется. Удаление собственного сообщения / обсуждения завершается успешно.                                     | —                         |
| SR-3 | Модератор может удалять сообщения / обсуждения участников, а также созданные им самим сообщения / обсуждения; сообщения / обсуждения / теги других модераторов он удалять не может.<br><br>OWASP ASVS: v5.0.0-8.2.1                                                              | Запрос на удаление сообщения / обсуждения / тега другого модератора отклоняется сервером, состояние данных после запроса не изменяется; запрос на удаление сообщений / обсуждений участников, а также собственных сообщений / обсуждений. | —                         |
| SR-4 | Пользователь не может создавать и удалять сообщения, обсуждения и теги от лица другого пользователя.<br><br>OWASP ASVS: v5.0.0-8.3.1                                                                                                                                             | При попытке создания или удаления сообщения / обсуждения / тега операция отклоняется сервером, данные на сервере не меняются.                                                                                                             | —                         |
