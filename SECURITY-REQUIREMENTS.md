# Требования безопасности

| ID   | Требование                                                                                                                                                                                                                                                                       | Критерий приёмки                                                                                                                                                                                                                                                                                                                     | Связанные T / D |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------- |
| SR-1 | Неавторизованный пользователь не должен иметь возможности создавать или удалять обсуждения и сообщения, а также создавать или удалять теги. Проверка должна выполняться сервером независимо от доступности соответствующих элементов интерфейса.<br><br>OWASP ASVS: v5.0.0-8.2.1 | Если неавторизованный пользователь отправляет запрос создания или удаления обсуждения, сообщения или тега, сервер отклоняет операцию. Состояние данных после запроса не изменяется.                                                                                                                                                  | T-4, D-1        |
| SR-2 | Участник может удалять только созданные им самим сообщения и обсуждения.<br>  <br>OWASP ASVS: v5.0.0-8.2.1                                                                                                                                                                       | При попытке участника удалить чужое сообщение / обсуждение сервер отклоняет операцию, состояние данных после запроса не изменяется. Удаление собственного сообщения / обсуждения завершается успешно.                                                                                                                                | T-1, D-1        |
| SR-3 | Модератор может удалять только сообщения / обсуждения участников, а также созданные им самим сообщения / обсуждения / теги.<br><br>OWASP ASVS: v5.0.0-8.2.1                                                                                                                      | Запрос на удаление сообщения / обсуждения / тега другого модератора отклоняется сервером, состояние данных после запроса не изменяется; запрос на удаление сообщений / обсуждений участников, а также собственных сообщений / обсуждений / тегов завершается успешно.                                                                | T-6, D-1        |
| SR-4 | Пользователь может создавать и удалять сообщения, обсуждения и теги только от своего лица.<br><br>OWASP ASVS: v5.0.0-8.3.1                                                                                                                                                       | При попытке создания или удаления сообщения / обсуждения / тега не от своего лица операция отклоняется сервером, данные на сервере не меняются; при попытке создания или удаления сообщения / обсуждения / тега от своего лица и наличии прав на действие операция завершается успешно.                                              | T-5, D-1        |
| SR-5 | Участник и модератор могут изменять данные авторизации для своего аккаунта.                                                                                                                                                                                                      | Попытка авторизации по новым данным проходит успешно. Попытка авторизации по старым данным завершается ошибкой.                                                                                                                                                                                                                      | T-2, D-3        |
| SR-6 | Данные авторизации хранятся только на сервере.                                                                                                                                                                                                                                   | После авторизации данные о логине и пароле пользователя не сохраняются в веб-клиенте.                                                                                                                                                                                                                                                | T-2, D-1        |
| SR-7 | Сервер фиксирует историю изменений данных с возможностью отката к прежним состояниям.                                                                                                                                                                                            | После создания или удаления сообщения / обсуждения / тега сервер сохраняет данные, по которым можно однозначно восстановить версию данных до применения изменения. При применении повторного создания или удаления данные до применения первого изменения продолжают быть доступными для однозначного восстановления.                | T-3, D-2        |
| SR-8 | Участник не должен иметь возможности создавать или удалять теги. Сервер проверяет роль пользователя при каждом таком запросе независимо от доступности элементов веб-интерфейса.                                                                                                 | При прямом запросе участника на создание или удаление тега сервер отклоняет операцию; теги и их связи с обсуждениями не изменяются. Корректный запрос модератора на создание тега или удаление собственного тега при соблюдении правил предметной области завершается успешно. Удаление тега другого модератора проверяется по SR-3. | T-7, D-1        |
